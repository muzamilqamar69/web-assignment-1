Objective / Theory

This lab introduces Cascading Style Sheets (CSS). You will learn how to apply inline, internal, and external CSS to style web pages, control layout, fonts, colors, and spacing.

Task 1 – Apply Borders and Padding

Apply border and padding properties to multiple paragraphs.

Code:
<!DOCTYPE html>
<html>
<head>
<style>
p {
  border: 2px solid powderblue;
  padding: 30px;
}
</style>
</head>
<body>
<h1>This is a heading</h1>
<p>This is a paragraph.</p>
<p>This is another paragraph.</p>
</body>
</html>

Task 2 – External CSS for Signup Page

Create an external CSS file and link it to a signup page for styling headings, text, and form elements.

Code:
/* mystyle.css */
body { background-color: lightblue; }
h1 { color: navy; font-family: Verdana; font-size: 36px; }
input[type=text], input[type=password] {
  width: 100%;
  padding: 10px;
  margin: 5px 0;
  border: 1px solid #ccc;
}
button {
  background-color: #04AA6D;
  color: white;
  padding: 10px;
  border: none;
  cursor: pointer;
}
button:hover { background-color: #45a049; }

<!DOCTYPE html>
<html>
<head>
<link rel="stylesheet" href="mystyle.css">
</head>
<body>
<h1>Sign Up</h1>
<form>
  <input type="text" placeholder="Email"><br>
  <input type="password" placeholder="Password"><br>
  <button>Register</button>
</form>
</body>
</html>
