This lab introduces JavaScript basics such as variables, functions, conditionals, and event handling. You will also create small interactive programs and perform input/output operations with users.

Task 1 – Display Entered Number

Use JavaScript to take user input and display it when a button is clicked.

Code:
<!DOCTYPE html>
<html>
<body>
<h3>Enter a number</h3>
<input type="number" id="myNumber" value="2">
<button onclick="showNumber()">Try it</button>
<p id="demo"></p>
<script>
function showNumber() {
  var x = document.getElementById("myNumber").value;
  document.getElementById("demo").innerHTML = "You entered: " + x;
}
</script>
</body>
</html>

Task 3 – Number Guessing Game

Write JavaScript code to generate a random number and check if the user guessed it correctly.

Code:
<!DOCTYPE html>
<html>
<body>
<script>
function playGame() {
  var res = Math.round(Math.random()*10);
  var num = prompt("Enter a number between 0–10", 0);
  if(num == res)
    alert("🎉 You won!");
  else
    alert("❌ Wrong! The correct number was " + res);
}
</script>
<button onclick="playGame()">Play Game</button>
</body>
</html>
