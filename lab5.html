Objective / Theory

This lab focuses on designing responsive web layouts using the <div> element and Bootstrap’s grid system. You will learn to structure headers, forms, and footers using CSS and Bootstrap for mobile-friendly design.

Task 1 – Responsive Form Using DIV and CSS

Create a responsive form with first name, last name, country, and subject fields styled using CSS.

Code:
<!DOCTYPE html>
<html>
<head>
<meta name="viewport" content="width=device-width, initial-scale=1">
<style>
* { box-sizing: border-box; }
input[type=text], select, textarea {
  width: 100%; padding: 12px; border: 1px solid #ccc; border-radius: 4px;
}
label { display:inline-block; padding: 12px 0; }
input[type=submit] {
  background-color:#04AA6D; color:white; padding:12px 20px; border:none; border-radius:4px;
}
.container { background-color:#f2f2f2; padding:20px; border-radius:8px; }
</style>
</head>
<body>
<h2>Responsive Form</h2>
<div class="container">
<form>
<label>First Name</label>
<input type="text" placeholder="Your name..">
<label>Last Name</label>
<input type="text" placeholder="Your last name..">
<label>Country</label>
<select><option>Pakistan</option><option>USA</option></select>
<label>Subject</label>
<textarea placeholder="Write something.." style="height:200px"></textarea>
<input type="submit" value="Submit">
</form>
</div>
</body>
</html>

Task 2 – Bootstrap Dropdown and Buttons

Use Bootstrap to create a dropdown menu with multiple colored buttons.

Code:
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
<div class="container text-center mt-4">
  <div class="btn-group">
    <button type="button" class="btn btn-primary">Primary</button>
    <button type="button" class="btn btn-primary dropdown-toggle dropdown-toggle-split" data-bs-toggle="dropdown"></button>
    <ul class="dropdown-menu">
      <li><a class="dropdown-item" href="#">Link 1</a></li>
      <li><a class="dropdown-item" href="#">Link 2</a></li>
    </ul>
  </div>
</div>
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
