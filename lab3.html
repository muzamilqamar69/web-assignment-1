Objective / Theory

This lab explores HTML5 forms and semantic elements. You will learn to create input fields, use form attributes, and structure webpages with semantic tags such as <header>, <section>, <article>, and <footer>.

Task 1 – Create a Login Form

Make a form with name, password, gender (using radio buttons), and submit/cancel buttons.

Code:
<!DOCTYPE html>
<html>
<head>
  <title>Get Identity</title>
</head>
<body>
  <p><b>Who are you?</b></p>
  <form method="post" action="">
    <p>Name: <input type="text" name="name"></p>
    <p>Password: <input type="password" name="password"></p>
    <p>Gender:
      <label><input type="radio" name="gender" value="m"> Male</label>
      <label><input type="radio" name="gender" value="f"> Female</label>
    </p>
    <input type="submit" value="Login">
    <input type="reset" value="Cancel">
  </form>
</body>
</html>

Task 2 – Create a Registration Form

Create a registration form using HTML5 input types such as email, password, and date.

Code:
<!DOCTYPE html>
<html>
<head>
  <meta name="viewport" content="width=device-width, initial-scale=1">
</head>
<body>
  <form>
    <h1>Register</h1>
    <p>Please fill in this form to create an account.</p>
    <hr>

    <label for="email"><b>Email</b></label>
    <input type="email" placeholder="Enter Email" name="email" required><br><br>

    <label for="psw"><b>Password</b></label>
    <input type="password" placeholder="Enter Password" name="psw" required><br><br>

    <label for="dob"><b>Date of Birth</b></label>
    <input type="date" name="dob" required><br><br>

    <label><b>Favorite Color</b></label>
    <input type="color" name="favcolor"><br><br>

    <p>By creating an account you agree to our <a href="#">Terms & Privacy</a>.</p>

    <button type="submit">Register</button>
  </form>
</body>
</html>

Task 3 – Using Semantic Elements

Use semantic elements like <header>, <main>, <article>, <section>, and <footer> to structure a webpage.

Code:
<!DOCTYPE html>
<html>
<head>
  <meta name="viewport" content="width=device-width, initial-scale=1">
</head>
<body>
  <header>
    <h1>Welcome to My Website</h1>
  </header>
  <section>
    <main>
      <article>
        This is the main content of the website.
      </article>
    </main>
    <aside>This is some extra sidebar content.</aside>
  </section>
  <footer>Copyright © 2025</footer>
</body>
</html>
