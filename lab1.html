Objective / Theory

The objective of this lab is to understand the basic structure and syntax of HTML. Students will learn how to create a simple webpage using basic HTML tags such as headings, paragraphs, lists, and images.

Task 1 – Create a Simple HTML Page

Create a basic HTML page that displays your name, roll number, and a short introduction.

Code:
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My First Web Page</title>
</head>
<body>
  <h1>Muhammad Muzamil Qamar</h1>
  <p>Roll No: FA23-BCS-287</p>
  <p>This is my first HTML webpage created for Lab 1.</p>
</body>
</html>

Task 2 – Using Headings and Paragraphs

Demonstrate the use of different heading levels and paragraphs.

Code:
<!DOCTYPE html>
<html>
<head>
  <title>Headings Example</title>
</head>
<body>
  <h1>This is Heading 1</h1>
  <h2>This is Heading 2</h2>
  <h3>This is Heading 3</h3>
  <p>This paragraph explains the usage of different heading tags in HTML.</p>
</body>
</html>

Task 3 – Working with Lists and Links

Create a simple webpage that includes an ordered list, unordered list, and hyperlinks.

Code:
<!DOCTYPE html>
<html>
<head>
  <title>Lists and Links</title>
</head>
<body>
  <h2>My Favorite Websites</h2>
  <ul>
    <li><a href="https://www.google.com">Google</a></li>
    <li><a href="https://www.github.com">GitHub</a></li>
    <li><a href="https://www.wikipedia.org">Wikipedia</a></li>
  </ul>
</body>
</html>
